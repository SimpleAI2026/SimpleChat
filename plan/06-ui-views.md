# 06 · UI 视图与视觉规范

> 状态：已按用户要求补充（2026-10-29）  
> 方向：**shadcn/ui 风格的黑白默认主题** —— 美观、简洁、大方；靠层级与留白，不靠花哨色。

## 0. 设计方向（3–5 行）

1. **目的**：嵌入宿主右侧的聊天侧栏，读消息、发消息、看工具调用，干扰宿主主画布要尽量少。  
2. **调性**：编辑感工具 UI（接近 shadcn / Linear）——冷静、清晰、可信。  
3. **记忆点**：高对比黑白、细描边、克制圆角；用户气泡近黑、助手近白描边。  
4. **约束**：纯前端 Web Component + Shadow DOM；可用 CSS 变量换肤，但**默认不引入彩色品牌主色**。  
5. **密度**：工具侧栏中等密度；消息区疏朗，Header/Composer 紧凑。

**明确不做**：紫蓝渐变、霓虹、重阴影、毛玻璃堆叠、彩色气泡默认皮肤、emoji 当图标。

- 默认 `layout="sidebar"`：`position: fixed; inset-block: 0; inset-inline-end: 0`。

- 侧栏与宿主之间用 **1px 边框** 分隔，不用厚阴影。

## 6. 默认主题 Token（shadcn 黑白）

映射接近 shadcn 的 `background / foreground / muted / border / primary`，前缀 `--sc-`。

### 6.1 Light（默认）

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `--sc-background` | `#ffffff` | 侧栏底 |
| `--sc-foreground` | `#0a0a0a` | 主文字 |
| `--sc-muted` | `#737373` | 次级文字 / hint |
| `--sc-muted-bg` | `#f5f5f5` | 浅底表面 |
| `--sc-border` | `#e5e5e5` | 发丝边框、分割线 |
| `--sc-primary` | `#171717` | 主按钮 / 用户气泡 |
| `--sc-primary-fg` | `#fafafa` | 主按钮文字 |
| `--sc-assistant-bg` | `#ffffff` | 助手气泡底 |
| `--sc-assistant-border` | `#e5e5e5` | 助手气泡边 |
| `--sc-ring` | `#0a0a0a` | focus ring |
| `--sc-radius` | `10px` | 控件圆角 |
| `--sc-radius-sm` | `8px` | 小芯片 / 图标钮 / tool 卡 |
| `--sc-radius-lg` | `12px` | 气泡 / 输入卡片 |
| `--sc-font` | `ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif` | |
| `--sc-font-mono` | `ui-monospace, SFMono-Regular, Menlo, monospace` | tool / code |
| `--sc-width` | `420px` | 侧栏宽 |
| `--sc-pad` | `20px` | 区块左右内边距（`--sc-space-5`） |
| `--sc-gap` | `16px` | 消息垂直间距（`--sc-space-4`） |
| `--sc-space-1`…`6` | `4 / 8 / 12 / 16 / 20 / 24px` | 统一 4px 间距网格 |
| `--sc-header-height` | `56px` | Header / 会话抽屉顶栏 |
| `--sc-icon-size` | `36px` | 图标按钮与发送钮触控高度 |

### 6.2 Dark（随宿主或 `color-scheme`，Should）

| Token | 建议值 |
| --- | --- |
| `--sc-background` | `#0a0a0a` |
| `--sc-foreground` | `#fafafa` |
| `--sc-muted` | `#a3a3a3` |
| `--sc-muted-bg` | `#171717` |
| `--sc-border` | `#262626` |
| `--sc-primary` | `#fafafa` |
| `--sc-primary-fg` | `#171717` |
| `--sc-assistant-bg` | `#0a0a0a` |
| `--sc-assistant-border` | `#262626` |

宿主可通过变量覆盖；**默认皮肤不提供高饱和 accent**。若需品牌色，覆盖 `--sc-primary` 即可（文档示例），不改变默认包观感。

### 6.3 组件规则

- **边框 > 阴影**：几乎不用 `box-shadow`；必要时仅 `0 1px 2px rgb(0 0 0 / 4%)`。  
- **主按钮**：实心 `--sc-primary`，悬停略提亮/压暗 4–6%。  
- **次按钮 / 图标钮**：透明底 + 悬停 `--sc-muted-bg` + 细边框可选。  
- **用户气泡**：`--sc-primary` 底 + `--sc-primary-fg` 字；右对齐。  
- **助手气泡**：白底 + 细边框；左对齐；Markdown 正文行高 ~1.6。  
- **工具卡**：`--sc-muted-bg`，等宽字体，左侧状态点（pending 中性转圈 / done 黑勾 / error 深灰叹号，避免刺眼红作默认强调，error 可用深色字+浅灰底）。  
- **圆角**：控件 8–10px，气泡/输入卡 12px；禁止过大 `rounded-2xl` 堆叠感。  
- **间距**：严格 4px 网格；消息区上下偏疏（24/16），Header/Composer 偏紧（56px / 输入卡）。  
- **Composer**：独立描边卡片 + 底栏 hint/发送对齐（参考主流聊天输入条密度，非品牌色）。  
- **动效**：150–200ms 透明度/位移；尊重 `prefers-reduced-motion`。

## 8. 验收（视觉）

1. 默认主题一眼为黑白 shadcn 风，无彩色渐变。  
2. 侧栏展开/会话列表/空状态/流式/工具卡 五种状态与 ASCII 结构一致。  
3. 改 `--sc-primary` 可换品牌色，且不破坏对比度（主按钮字色随 primary-fg）。  
4. 在浅色宿主页上边框清晰、不「发灰糊成一片」。
